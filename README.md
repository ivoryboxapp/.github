# Ivory Box

Ivory Box is a new set of open-source apps. The norm today is handing your data over to others; it's time we put a stop to that and started retaining it.

What you own is truly yours.

## Get started

Install the Ivory Box shell, open the Marketplace and download the apps you want from this organisation.

## Built with

Rust and Tauri 2.
